## 一、底层机制：为什么你的节点看 Netflix 只能看自制剧？

很多剧迷在购买代理后经常发现：
“明明 Netflix 能登录上去，但搜索《绝命毒师》、《寄生虫》或者当地热门影视剧时，搜出来的全都是 Netflix 自制剧（Netflix Originals）？”
“连上节点看 YouTube 偶尔能跑，但在电视机或 Apple TV 上看 4K HDR 却一直卡顿转圈？”

这背后是流媒体巨头与机房代理长达十余年的技术攻防战。

### 1. 原生 IP 解锁（Native Unlock） vs DNS 解锁（SNI Proxy）
- **原生解锁（最高质量）**：机场节点服务器直接租用当地运营商（如香港 HKT/HGC、台湾中华电信、日本 NTT/Softbank、新加坡 Singtel）的本地广播 IP。流媒体服务器判定该请求来自本土真实家庭用户，**无条件放行全量地区版权片库**，且音频支持 Dolby Atmos（杜比全景声）与 Dolby Vision（杜比视界）。
- **DNS 分流解锁（易失效）**：机场节点本身是廉价机房 IP，无法通过 Netflix 校验，服务商通过在节点上配置 SNI 代理，将认证流量劫持并转发给另一台原生小机器。这种方案稳定性差，一旦中继机器超载或被封，全线节点会瞬间变成仅自制剧。

### 2. 8K 与 4K 极客播放的“单线程吞吐”硬指标
观看 4K HDR 视频需要恒定的 25Mbps 瞬时码率；而观看 YouTube 8K 60fps 甚至 AV1 高码率编码视频，瞬时网络吞吐需要高达 **120Mbps~200Mbps**。
普通中继机场虽然多线程测速好看，但单线程连接极弱，只要丢包率达到 1%，TCP 拥塞算法就会强制窗口减半，导致播放器被迫降低画质。

```
[视频客户端] ➔ (普通公网丢包 3%) ➔ TCP 窗口崩溃 ➔ 视频严重缓冲降权 480P 😭
[视频客户端] ➔ (IEPL 物理专线 0 丢包) ➔ 持续跑满 800Mbps ➔ 8K 杜比视界秒开极速缓冲 🚀
```

## 三、大屏端与移动端流媒体最佳设置指南

为了在大屏电视（Apple TV、Google TV、索尼/三星电视）与手机上获得最完美的音画体验，请务必注意以下 3 点配置：

### 1. 节点区域与中文字幕的对应关系
- **中国香港（HK）节点**：繁体中文字幕最全，适合追绝大多数院线新片与华语影视。
- **中国台湾（TW）节点**：部分海外大片在台湾地区拥有独家早播权，且中文字幕翻译最为地道。
- **新加坡（SG）节点**：原生简体中文字幕（Simplified Chinese）最丰富，界面最为友好。
- **日本（JP）节点**：日漫新番全网最快同步上线，部分动漫独家支持无删减版本。
- **美国（US）节点**：影视版权片库总量全球最大，但部分冷门老片可能仅配有英文字幕。

### 2. Apple TV 与家庭软路由代理分流
在家庭大屏场景下，推荐在 Apple TV 上安装 **Stash** 或 **Surge** 客户端，或通过主路由 / 旁路由开启透明代理。在策略组中将 `Netflix`、`Disney+`、`YouTube` 域名集合单独划入一个专线策略组，家庭其他局域网设备上网走国内直连，互不抢占带宽。

### 3. 关闭客户端内的“省流量模式”
在 Clash Verge 或小火箭等客户端中，切勿开启带有内容压缩特性的省流量插件，否则会导致播放器获取不到原画视频流，锁死在 720P。

## 常见问题与解答 (FAQ)

### Q1：为什么连接了专线节点，Netflix 依然提示“您似乎在使用未解封的代理”？
这说明你当前连接的节点 IP 已经被 Netflix 的反代理防火墙列入临时风控黑名单。只需在客户端的节点列表中切换至备用解锁节点（通常机场会标注 `NF` 或 `流媒体解锁`），重启 Netflix App 或刷新网页即可恢复。

### Q2：看 YouTube 4K 必须开启 TUN 模式吗？
电脑端浏览器观看通常系统代理即可；但在使用客户端桌面应用、第三方播放器（如 IINA、PotPlayer）调用网络流、或者使用外置投屏协议时，开启客户端的 **【TUN 虚拟网卡模式】** 能确保所有数据流毫无遗漏地走专线加速通道。

### Q3：为什么看视频跑几百兆很流畅，但画质却不能手动调节到 4K？
Netflix 的 4K 播放受到硬件 DRM（数字版权保护）限制。Windows 电脑必须使用 Edge 浏览器或官方 App，并配备支持 HDCP 2.2 的 4K 显示器；Mac 电脑需使用 Safari 浏览器；Android 手机必须通过 Widevine L1 认证。若硬件不支持，即便网络千兆也只能最高输出 1080P。

### Q4：流媒体解锁专线一个月大概需要多少流量？
日常观看 1080P 视频每小时消耗约 1.5GB~3GB 流量；观看 4K HDR 视频每小时消耗约 7GB~10GB 流量；8K 视频每小时消耗约 20GB~30GB。重度追剧用户建议选择月流量在 **300GB~1000GB** 以上的专线套餐（如环球梯或榴莲云）。

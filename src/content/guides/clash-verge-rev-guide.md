## 二、前置准备：获取专线机场订阅链接

客户端本身只是网络中转的调度外壳，不自带任何海外节点。在正式配置前，你需要准备好一条高可用专线机场的订阅链接：

1. 登录本站推荐的物理专线机场（如 [闪电鼠](/airports/shandianshu) 或 [大佬云](/airports/dalaoyun)）用户中心。

3. 点击 **【复制 Clash 订阅链接】**（通常为一条以 `https://` 开头的加密 URL，支持 SS、VLESS、Trojan、Hysteria 2、TUIC 等现代协议）。

## 三、一步步配置流程（保姆级实操）

### 步骤一：软件安装与初始化
1. **Windows 安装**：双击下载的 `.exe` 安装程序，按照提示点击“下一步”完成安装。首次运行时建议右键选择“以管理员身份运行”，便于后续写入 TUN 网卡驱动。
2. **macOS 安装**：打开 `.dmg` 文件，将 `Clash Verge` 图标拖拽到 `Applications`（应用程序）文件夹中。初次打开若提示“无法验证开发者”，请前往系统的 **【设置 ➔ 隐私与安全性】** 中点击“仍要打开”。
3. **中文语言切换**：点击左侧齿轮图标 **【Settings】（设置）**，在 `Language` 下拉框中选择 **【简体中文】**。

### 步骤二：导入订阅与更新节点
1. 点击左侧主导航栏的 **【订阅】 (Profiles)** 选项。
2. 在顶部输入框中粘贴刚才复制的机场订阅链接。
3. 点击右侧的 **【保存】 (Save)** 按钮。
4. 客户端会自动从专线机房拉取最新的节点配置。导入成功后，列表会显示该订阅卡片，右键点击卡片可选择 **【刷新】** 实时更新节点。

### 步骤三：代理模式选择（规则分流 / 全局 / 直连）
点击左侧 **【代理】 (Proxies)** 导航栏，顶部有三种核心模式可供切换：
- **【规则】 (Rule) —— 强烈推荐 99% 的用户日常开启**：
  - 客户端会根据内置的 Geosite 与 GeoIP 规则库进行智能路由判定。
  - 访问国内网站（百度、微信、淘宝、B站等）自动走“直连”，不耗费机场流量且延迟为零。
  - 访问海外受限服务（Google、GitHub、YouTube 等）自动走“代理节点”。
- **【全局】 (Global)**：强制所有联网请求全部经过海外代理节点，通常仅用于调试海外独立 IP 或访问冷门未收录站点。
- **【直连】 (Direct)**：所有流量均不走代理，相当于关闭科学上网。

在规则模式下，展开 `PROXY` 或 `节点选择` 策略组，点击选择一个延迟最低的香港、日本、新加坡或美国专线节点。

### 步骤四：开启代理与 TUN 模式（解决应用不走代理问题）
1. **基础系统代理**：
   - 点击左侧 **【设置】**，找到 **【系统代理】 (System Proxy)** 开关，将其切换为开启状态。此时打开 Chrome 或 Edge 浏览器即可正常访问海外网页。
2. **开启 TUN 虚拟网卡模式（关键进阶）**：
   - 许多外服游戏（Steam/Apex/瓦罗兰特）、命令行终端（Git/Curl）、或部分不遵循 Windows 系统代理的应用（如 Telegram 桌面版、部分 AI 客户端）经常出现“浏览器能上但软件连不上”的痛点。
   - 开启方法：在左侧 **【设置】** 页面，找到 **【TUN 模式】** 开关。
   - 首次开启时，客户端会提示安装虚拟网卡服务（Service Mode），点击授权并允许 Windows 防火墙放行。
   - 开启成功后，TUN 虚拟网卡将在内核层接管整机全部 TCP/UDP 流量，实现真正的全局透明加速！

## 四、AI 工具与流媒体解锁专项设置

海外高端 AI 工具与流媒体平台有着极其苛刻的 IP 审查与风控机制，配置不当极易遭遇封号或降权：

1. **ChatGPT & Claude 专项分流**：
   - 在左侧 **【代理】 (Proxies)** 页面中，查看机场配置是否自带 `OpenAI / AI 工具` 独立策略组。
   - 务必为该策略组绑定 **原生住宅 IP 或高纯净度节点**（优先选择美区 US 或日区 JP 专线，尽量避免公网中继被万人共用的拥挤节点）。
   - 保持节点 IP 固定，切勿在一次对话中频繁频繁切换不同国家的节点，以防触发 OpenAI 异地安全风控。
2. **Netflix / Disney+ / YouTube Premium 流媒体分流**：
   - 在流媒体策略组中，选择带有 `原生解锁` 或 `NF` 标识的节点（推荐香港、新加坡或台湾节点），既能享受低延迟 4K HDR 极速缓冲，又能完整解锁当地版权剧集。

## 五、常见故障排查 (FAQ)

### Q1：节点全部测速失败、显示超时或标红（Timeout）？
1. **检查本机系统时间**：90% 的 TLS 握手失败均由本地时钟误差引起。在 Windows/Mac 系统设置中打开“自动同步 Internet 时间”，确保误差在 30 秒以内。
2. **检查订阅是否过期或流量耗尽**：登录机场用户中心查看账户余额与套餐剩余流量。
3. **安全软件误杀内核**：部分国产杀毒软件会拦截 `mihomo.exe`，请在安全中心将 Clash Verge Rev 所在目录加入信任白名单。

### Q2：打开系统代理后，电脑无法上网、网页提示“拒绝连接”？
- **原因分析**：通常是之前非正常关机或强制退出客户端，导致 Windows 系统代理端口未被自动清理。
- **解决方法**：打开 Windows 设置 ➔ 【网络和 Internet】 ➔ 【代理】，检查“使用代理服务器”是否被勾选在无效端口（如 127.0.0.1:7890）。重新打开 Clash Verge Rev，先关闭系统代理开关，再重新开启一次即可自动纠正注册表。

### Q3：DNS 泄漏与端口占用排错（Port 7890 冲突）？
- 若提示 `Port 7890 already in use`，说明后台有残留的原版 CFW 或其他代理程序在运行。
- 在 Clash Verge Rev 【设置】 ➔ 【Verge 设置】 中，将 Mixed Port（混合端口）修改为 `7897` 或 `10808` 等未被占用的端口，重启客户端即可。
- 开启 TUN 模式后，请在设置中打开 `内置 DNS / Fake-IP` 模块，能有效防止运营商 DNS 劫持与 ISP 泄漏。

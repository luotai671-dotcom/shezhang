> **【直接回答】**v2rayN 是 Windows 平台上生态最成熟的开源图形客户端。内置 Xray-core 与 sing-box 内核，支持从最古老的 Shadowsocks 到最新 VLESS-Reality、Hysteria 2、TUIC 全协议栈。

  - GitHub 官方发布页：`https://github.com/2dust/v2rayN/releases`

## 三、一步步配置流程（保姆级实操）

### 步骤一：软件解压与运行
1. 将下载的压缩包解压到一个固定的英文路径文件夹中（例如 `D:\v2rayN`，切勿放在桌面或含有中文特殊字符的路径）。
2. 双击 `v2rayN.exe` 启动。若系统提示缺少 .NET 运行时，根据弹出的微软官方窗口点击下载安装即可。
3. 启动后，Windows 任务栏右下角托盘区会出现 v2rayN 的蓝色/红色小 V 图标。

### 步骤二：导入订阅与更新节点
1. 打开主界面，点击顶部菜单栏的 **【订阅分组】 ➔ 【订阅分组设置】**。
2. 在弹出窗口左下角点击 **【添加】**：
   - **备注**：填写机场名称（例如：闪电鼠专线）。
   - **可选地址 (Url)**：粘贴刚才复制的机场订阅链接。
3. 点击 **【确定】** 保存。
4. 返回主界面，点击顶部 **【订阅分组】 ➔ 【更新全部订阅(不通过代理)】**。
5. 几秒钟后，所有专线节点将被加载到主界面列表中。

### 步骤三：代理模式选择与节点选择
1. 在节点列表中按 `Ctrl + A` 全选，按 `Ctrl + R` 或右键点击选择 **【测试服务真连接延迟 (Ping)】**。
2. 双击选择一个延迟最低（如 20ms~40ms）的香港或日本专线节点，将其设为活动节点（字体会变为加粗高亮）。
3. 在底部中央的 **【路由】** 下拉框中，务必选择 **【绕过大陆 (Whitelist)】**。
   - 国内网页直连，国外网页走代理。

### 步骤四：开启代理与 TUN 模式
1. 观察底部的 **【系统代理】** 开关：
   - 切换为 **【自动配置系统代理】**（图标变红），此时浏览器即可打开 Google 与 YouTube。
2. **开启 TUN 模式（全流量接管）**：
   - 勾选底部的 **【启用 Tun 模式】** 复选框。
   - 首次启用时系统会安装虚拟网卡驱动，之后可让所有外服游戏与终端命令行直接走物理专线加速。

## 五、常见故障排查 (FAQ)

### Q1：提示“无法连接到远程服务器”或“基础连接已经关闭”？
- 打开 Windows 设置 ➔ 时间和语言 ➔ 立即同步时钟，确保时区为 UTC+8 且时间准确。

### Q2：退出 v2rayN 后电脑完全上不了网？
- 退出客户端前请确保将底部的【系统代理】切换为【清除系统代理】。若已退出导致断网，进入 Windows 代理设置中关闭手动代理服务器即可。
